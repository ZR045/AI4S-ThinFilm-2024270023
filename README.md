# AI4S Thin-Film Project — 2024270023

Course project: **MLP-Based Spectral Prediction and Data-Driven Design of Multilayer Dielectric Thin Films**.

## Student-specific parameters

- Student ID: `2024270023`
- Target wavelength: `680 nm`
- `seed = 270023`
- `design_seed = 270024`

These values follow the course rule:
`lambda_target = 450 + 10 * (N mod 31)` nm, where `N` is the last two digits of the student ID,
and `seed` is the integer represented by the last six digits.

## Physical model

The multilayer is:

`Air / H / L / H / L / Glass`

with:

- `n_H = 2.30`
- `n_L = 1.45`
- `n_s = 1.52`
- each layer thickness in `[40, 180] nm`
- wavelength range `400–800 nm` with `10 nm` spacing (`41` wavelength points)
- normal incidence, lossless media, no dispersion

The forward spectra are calculated using the 2×2 characteristic-matrix transfer matrix method (TMM).

## Dataset and MLP

The code generates `5000` structures using `seed = 270023` and makes one fixed split:

- 4000 training samples
- 500 validation samples
- 500 test samples

The MLP architecture is:

`4 → 128 → 128 → 64 → 41`

with ReLU activations and MSE loss.

The training-size study uses the **first 500, 1000, 2000, and 4000 samples from the same fixed 4000-sample training pool**. Validation and test sets remain unchanged.

## MLP-assisted design

The design stage uses `design_seed = 270024` to generate `10000` new thickness combinations.

By default, this repository **maximizes reflectance at 680 nm** because the course sheet says to rank candidates by target-wavelength reflectance but does not explicitly state ascending or descending order. If the instructor requires minimum reflectance instead, change:

```python
DESIGN_OBJECTIVE = "minimize"
```

in `config.py`.

The workflow is:

1. MLP predicts all 10000 candidate spectra.
2. Rank candidates by predicted reflectance at 680 nm.
3. Keep the MLP Top 10.
4. Recalculate those Top 10 using TMM.
5. Rank by TMM reflectance and report the final Top 5.
